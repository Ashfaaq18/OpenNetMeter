
# OpenNetMeter

A simple program to monitor your network/data usage. Made for the average windows user.
https://opennetmeter.com

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-support%20OpenNetMeter-FFDD00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/ashfaaq18)

## Description

This program provides the following features,

- network speed.
- current connection's session data usage.
- Data usage for today.
- retrieve detailed data usage for any date range within your chosen history retention (60 days by default, up to forever), and export it as CSV, JSON or an HTML report.
- record per-app data usage between Start and Stop (e.g. a game download or a video call), and export the result.
- follows the network adapter Windows actually uses for internet traffic, so full-tunnel VPNs (WireGuard etc.) are counted per app. You can also pin a specific adapter.
- A mini widget to show the network speed (can be placed over the taskbar), plus your usage for the session or since a date you choose.

## Installation

> This installer may trigger a Windows security warning because it is not code-signed. This is not a sign of malware. I do not currently have a code-signing certificate, and those cost money. If you downloaded this from the official OpenNetMeter GitHub release page, it is safe to continue.

1. Download the latest release .msi from this repository and run it (no more .zip format).
2. This application requires admin privileges.
3. Optional : To add this as a startup program, go to the settings tab and tick the checkbox.

> no more .zip format and a separate .net runtime installation required :)

## Uninstallation

1. simply uninstall from the control panel.
(for versions before, 0.12.1 and below, Simply delete the folder.)
